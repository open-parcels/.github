# Security policy

Please report vulnerabilities privately through GitHub's security advisories: open the affected
repository, go to **Security → Report a vulnerability**. Do not open a public issue.

Include the affected version, steps to reproduce and the impact. Never include real tracking
numbers, addresses, tokens or other personal data in a report.

Open Parcels is in early development. Only the newest version 2 build (the `main` branch, published
as the `:dev` image) gets fixes; version 1 (`:latest` until 2.0.0, branch `legacy-ts`) does not.
