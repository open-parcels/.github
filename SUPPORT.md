# Support

- **Install guides and documentation:** https://open-parcels.github.io
- **Something broken or a feature idea:** open an issue in the matching repository using its form.
  Remove all personal data (tracking and order numbers, names, addresses, emails, tokens) first.
- **Security problems:** see [SECURITY.md](SECURITY.md); never report them in public.

Open Parcels is a volunteer project; there is no paid support and no response-time guarantee.
